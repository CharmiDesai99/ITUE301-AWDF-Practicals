# Practical 1: Introduction to React and Component Architecture

## Objective
To build a modular React portfolio application using functional components and unidirectional data flow.

## Implementation Details
- Built reusable components: Header, About, Skills, ProjectCard, Contact.
- Structured data in portfolio.js passed down via props.
- Styled using clean, responsive Vanilla CSS with flexbox and css grid.
