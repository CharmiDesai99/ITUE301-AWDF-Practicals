# Practical 4: Building a RESTful API with Node.js and Express

## Objective
To create an Express.js REST API with full CRUD endpoints for Task Management.

## Endpoints
- GET /tasks: Retrieve all tasks
- GET /tasks/:id: Retrieve task by ID
- POST /tasks: Create a new task (validates required fields)
- PUT /tasks/:id: Update existing task
- DELETE /tasks/:id: Delete task by ID

## How to Run
`ash
cd backend
npm install
npm run dev
`
